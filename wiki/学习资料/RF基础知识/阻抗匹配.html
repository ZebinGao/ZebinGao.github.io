阻抗匹配：最大输出功率、共轭与 VSWR

匹配（matching）是 RF 工程的第一课：让源与负载”对上暗号”，功率才能痛快交出去。这张卡片讲清它的三个支柱——L/C 的能量语言、共轭匹配定理、VSWR 度量；具体怎么”算着走”见「Smith圆图」卡片，工程现场见「RF功率链路」卡片。

1. L 与 C：两种能量仓库

匹配网络里只有两种基本元件，各管一种能量：

  • 电感 L——磁场的能量：电流建立磁场，储能 $W_L = \frac{1}{2}LI^2$。电流想变，L 反对（$v_L = L\,di/dt$）——电压超前电流 90°
  • 电容 C——电场的能量：电压建立电场，储能 $W_C = \frac{1}{2}CV^2$。电压想变，C 反对（$i_C = C\,dv/dt$）——电流超前电压 90°

正负号相反的”抵抗”：感抗 $X_L = +\omega L$、容抗 $X_C = -1/\omega C$——一个正一个负，正好抵消。LC 并联或串联谐振时磁场能与电场能周期性互换（$\omega_0 = 1/\sqrt{LC}$），对外不再吞吐无功——谐振就是两种能量仓库的对口交换达到平衡。匹配网络的全部魔法，就是用 L 和 C 搭一个能量中转站，把负载的”能量口味”改造成源想要的 50 Ω 纯电阻。

2. 共轭匹配：输出功率最大的条件

定理：源内阻抗 $Z_S = R_S + jX_S$，负载 $Z_L = R_L + jX_L$，当

时，负载获得最大功率：

物理拆解（两步都少不了）：

  1. 虚部抵消（$X_L = -X_S$）：感抗容抗正负抵消，回路只剩纯电阻——电流不被无功分量拖后腿，功率因数为 1，能量不再在源负载间空跑
  2. 实部相等（$R_L = R_S$）：电阻分压最均衡的Point——负载电阻太大电流上不去、太小电压上不去，$R_L = R_S$ 时乘积 $I^2R_L$ 最大

从反射波看同一件事：共轭匹配时 $\Gamma = 0$——源看到的负载就是它的复共轭，入射波无反射地被吸收；内阻上损耗恰为一半（50% 效率上限正是最大功率传输的代价）。

工程语言：发生器内阻 50 Ω 纯阻 → 负载也要 50 Ω 纯阻。负载若带电抗（等离子体就是”几欧电阻串几百 pF 电容”），就用匹配网络把它变换成 50 Ω——匹配器的本质是一台”阻抗变压器”（见「RF功率链路」卡片）。

3. VSWR：匹配质量的温度计

驻波比（Voltage Standing Wave Ratio）：部分反射时，线上电压包络的最大值与最小值之比：

VSWR $ \Gamma $ 反射功率 状态
1.0 0 0% 完美匹配（理想）
1.5 0.20 4% 良好
2.0 0.33 11% 可接受
3.0 0.5 25% 差——该修了
∞ 1 100% 全反射（开路/短路）
  • 回波损耗 $RL = -20\log_{10}|\Gamma|$（dB）与 VSWR 一一对应：VSWR 1.5 ↔ RL 14 dB
  • 工程惯例：VSWR < 1.5 为良好，> 2 触发多数发生器的降功率保护
  • 注意 VSWR 只看幅度，不含相位——它告诉你”有多不匹配”，不告诉你”往哪边调”。往哪边调要看相位（Smith 圆图或阻抗显示），这正是下一张卡片的主题

4. 为什么匹配这么重要（三本账）

  1. 功率账：反射功率在源内阻上变成热——VSWR 3 时 1/4 的功率白烧
  2. 安全账：反射叠加的电压腹点可能击穿电缆/接头/腔体绝缘；源末级功率管直接面对反射功率，寿命骤减——发生器 VSWR 保护就是保命电路
  3. 工艺账（等离子体设备）：入腔功率不稳 = 等离子体密度不稳 = 工艺漂移。auto-match 的秒级响应是刻蚀重复性的隐形支柱

5. Q 值与带宽：匹配的代价

匹配网络 sharp（高 Q）则带宽窄、对负载漂移敏感；Q 低则带宽宽但变换”力度”分散——窄带大变换比天然高 Q。等离子体点火时负载剧变，匹配器要能被”拽着走”——为什么 auto-match 电机要快、网络 Q 不能太高，根源都在这。
