Smith 圆图：阻抗匹配的地图

1939 年，贝尔实验室的 Philip H. Smith 发明这张图，把复阻抗匹配的复数运算压缩成”在图上走路”。九十年来它没被计算机取代——每台网络分析仪屏幕上仍默认叠着它，RF 工程师调匹配时脑中的”地图”就是它。这张卡片讲怎么读、怎么走。

1. 构造：把阻抗塞进一个圆

核心思想：直接画阻抗平面（0 到 ∞ 半平面）没法用——把它映射到反射系数 $\Gamma$ 的复平面上，所有阻抗就都落进单位圆内了（$|\Gamma| \le 1$）。

归一化阻抗 $z = Z/Z_0 = r + jx$，与反射系数的关系：

地标：

  • 圆心：$z = 1$（即 $Z = Z_0 = 50\ \Omega$），$\Gamma = 0$——匹配点，所有匹配的目的地
  • 左端点：$\Gamma = -1$，$z=0$——短路
  • 右端点：$\Gamma = +1$，$z=\infty$——开路
  • 上半平面：$x>0$ 感性；下半平面：$x<0$ 容性——看负载点落在哪半边，立刻知道该补电感还是电容
  • 实轴：纯电阻线；单位圆边界：纯电抗（无损 LC）

图：标准 Smith 圆图。红色为等电阻圆（r = 0.2、0.5、1、2、5，全部汇聚于右侧开路点），蓝色为等电抗圆（x = ±0.2、±0.5、±1、±2、±5，同样汇聚于开路点）；左端为短路、圆心为匹配点，上半圆感性、下半圆容性。

2. 两个圆族：读出任一点的阻抗

  • 等电阻圆：$r$ 相同的点连成的圆，圆心都在实轴上，与 $x=0$ 轴相切于右端点——$r=0$ 是外边界大圆，$r=1$ 过圆心，$r\to\infty$ 缩成右端点
  • 等电抗圆：$x$ 相同的点连成的圆弧，圆心在与实轴垂直的线上，弧两端都落在边界上——上半弧为感（+x）、下半为容（−x）

任意负载点读法：找到它所在的等 r 圆与等 x 圆，交点即 $(r, x)$，乘以 $Z_0$ 得真实阻抗。例：点落在 $r=0.5$、$x=-1$ → $Z = 25 - j50\ \Omega$——一个偏小带容性的负载。

3. 在图上”走路”：三类标准动作

（1）沿线移动（转圈）：沿传输线移动距离 $l$，$\Gamma$ 的幅度不变、相位旋转 $-2\beta l$——绕圆心顺时针（向源方向）转，每 $\lambda/2$ 转满一圈（阻抗沿线周期性重复）。半波长传输线 = 回到原点；$\lambda/4$ = 关于圆心镜像（$Z_{in}=Z_0^2/Z_L$ 的圆图版本）。

（2）加串联元件（沿等电阻圆走）：串 L（感抗 +x）→ 沿等 r 圆逆时针（上半圆内移动）；串 C（容抗 −x）→ 沿等 r 圆顺时针。

（3）加并联元件（沿等电导圆走）：并 L → 沿等电导圆顺时针（导纳图语言：感纳 −b）；并 C → 逆时针（容纳 +b）。并联分析用导纳圆图——同一张图转 180°（以圆心为中心），电阻圆变电导圆、电抗圆变电纳圆。

4. L 型匹配：从负载走回圆心的路

最简匹配网络：一个电感 + 一个电容，两种拓扑（负载先串后并 / 先并后串）。设计过程就是在圆图上规划路线：

  1. 标出归一化负载点 $z_L$
  2. 选一条两步路线：先沿等 r 圆（串联）走到 $r=1$ 圆上，再沿 $g=1$ 圆（并联）回到圆心——或反过来
  3. 两段弧长直接读出所需 $X$ 与 $B$ → 换算成 L 值 C 值：
  1. 频率已知（如 13.56 MHz）、$Z_0=50\ \Omega$ 代入即得元件值——圆图上量出来的就是元件值

两条路线对应两个解（高 Q / 低 Q 各一），按带宽要求选用（Q 与带宽见「阻抗匹配」卡片第 5 节）。

5. 快捷读图经验

  • 负载点在下半圆（容性）→ 两条路都从”串 L 或并 L”开始——补感抗
  • 点离圆心越远（$|\Gamma|$ 越大），路线越长、Q 越高、带宽越窄
  • 频率扫描 = 负载点在图上描出一条小轨迹——看轨迹绕哪个方向、离圆心多远，负载的频率特性一目了然（谐振点 = 轨迹穿过实轴处）
  • 实操口诀：串联沿电阻圆、并联沿电导圆、向源顺时针、每半波长一圈——记住这四句，圆图就废不了
