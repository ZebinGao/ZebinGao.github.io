UV：光子化学——DBD、汞灯、光子切断与固化

等离子体给化学供能靠电子碰撞；平行路线是光子（UV）直接打断化学键（光解/光子切断）。这条卡片把三件事串成线：UV 从哪来（DBD 与汞灯）、光子怎么断键（按能量切断）、断键之后干什么（UV 固化调应力）。

1. UV 源之一：DBD（介质阻挡放电）

气体放电按气压与结构演化出许多形态（辉光、电弧，见《等离子体在半导体设备中的应用》的「气体放电」卡片）。要在大气压下稳定维持非平衡等离子体（不放成电弧），经典手法是 DBD（Dielectric Barrier Discharge）：

  • 结构：两电极间至少一面覆盖介质层（石英、陶瓷、玻璃），气隙 0.1–几 mm
  • 介质的作用：微放电（流注）一旦导通，电荷沉积在介质表面、局部电场被抵消——放电自动熄灭；电压换向后又在别处击穿。宏观是均匀”冷等离子体”，微观是每秒成千上万个微放电脉冲——介质就是自动保险丝，把电弧掐死在摇篮里
  • 特点：1 atm 工作（无需真空泵）、气体近室温、大面积
  • 应用：臭氧发生器（O₂ DBD → O₃）、材料表面活化/亲水处理、大尺寸基板清洗；激发态退激还发出 UV——DBD 准分子灯（Xe₂* 发 172 nm 真空紫外）本身就是 UV 源

2. UV 源之二：汞灯

低压汞灯（汞蒸气放电灯）是经典”光子工厂”——本质也是气体放电（汞蒸气辉光放电，帕邢区间工作），只是把放电发光用足：

谱线 光子能量 能打断什么
253.7 nm 4.9 eV N–H、O–H、C–H、Si–H 等大多数键
184.9 nm 6.7 eV 几乎所有有机键；还能光解 O₂ 产 O₃
  • 光子能量换算：$E = hc/\lambda = \dfrac{1240}{\lambda\,[\mathrm{nm}]}\ \mathrm{eV}$
  • 184.9 nm 被空气强吸收，只在真空/纯氮中用；253.7 nm 是工业 UV 主力
  • UV-Ozone 清洗：185 nm 产 O₃、254 nm 激发有机分子，协同把表面有机污染氧化成 CO₂+H₂O 挥发——晶圆/光学件装片前最后一道洁净工序，可达”原子级清洁”（接触角 <5°）

3. 光子切断：按能量断键

光解（photolysis / 光子切断）：光子能量 $h\nu \ge$ 键能时键被直接打断——与电子碰撞断键不同，光子过程选择性强（波长挑键）、不带电荷损伤：

键 键能 254 nm（4.9 eV）能否切断
Si–H ~3.0 eV ✓ 轻松
N–H ~4.0 eV ✓
C–H ~4.3 eV ✓
Si–N ~4.5 eV ✓ 勉强
Si–O ~8.3 eV ✗ 需深紫外（<150 nm）

对 PECVD 膜的意义：SixNyHz 里的 Si–H、N–H 键正是紫外光子的软柿子（膜成分见「PECVD」卡片）——光子切断打开了不加热改性的大门。

4. UV 固化：把应力拉向高张应力

UV cure（紫外固化/退火）：对刚沉积的含氢膜（SiN、SiCN、low-k）做 UV 辐照，链式反应：

  1. 光子切断 Si–H、N–H（及 C–H、Si–C）键
  2. 释放的 H 复合成 H₂ 扩散逸出（膜变薄变密）
  3. 悬挂键重新交联成更强骨架键（Si–N、Si–O、Si–C）
  4. 体积收缩 + 网络致密化 → 膜应力向张应力（tensile）方向移动

工程价值——应力是可”光调”的旋钮：

  • PECVD SiN 沉积态偏压应力（低频轰击”锤”出来的，见「PECVD」卡片第 4 节）；UV 固化把应力大幅拉向高张应力（high tensile）——与低频旋钮配合，可精确落点零应力或指定应力值
  • 为什么要高张应力：钝化 SiN 要压应力封住芯片防潮；而柔性封装应力缓冲、晶圆翘曲补偿等应用要高张应力膜对冲叠层里的压应力——UV 固化是获得高张应力最温和的手段（不加热、不轰击）
  • low-k 介质：UV 切断 Si–CH₃/CH 基团致密化骨架同时保住纳米孔隙——机械强度与低 k 值的平衡术
  • 光源选择：汞灯（宽谱成熟）、准分子灯（172/222 nm 单色）、UV-LED（365/395 nm，只能断最弱的键）——按目标键能选波长

5. 三条供能路线的合流

同一个目标（改材料），三条物理路线：

路线 能量载体 激活方式 损伤
热 分子热运动 高温 热预算大（LPCVD/SACVD，见「SACVD」卡片）
电子碰撞 等离子体电子（1–20 eV） 非弹性碰撞 离子轰击损伤（PECVD，见「PECVD」卡片）
光子 UV 光子（3–10 eV） 光吸收断键 几乎无电荷损伤（本卡片）

电子与光子是”近亲”——1 eV 电子与 1240 nm 光子是同一份能量，只是 delivery 方式不同；DBD 与汞灯这对放电兄弟，一个偏重碰撞化学、一个偏重发光——放电物理与光化学在薄膜工艺里殊途同归。
